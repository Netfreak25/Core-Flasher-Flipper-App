Core Flasher build instructions
==============================

The current portable build instructions are in README-build.txt and
BUILD_NOTES.md. They replace the previous v3 instructions in this file.

Run build-unleashed.cmd, build-momentum.cmd or build-roguemaster.cmd to match
your installed firmware. The latest output is dist\core_flasher_distribution.fap.

See README.md for application usage and the manual Unleashed source-tree build.
